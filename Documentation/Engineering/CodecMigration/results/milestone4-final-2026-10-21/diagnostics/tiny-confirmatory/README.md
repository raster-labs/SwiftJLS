# Predeclared tiny-case confirmation, 21 October 2026

This is one bounded confirmatory campaign of the unchanged original public-API Consumer, using the frozen canonical `bee49a2ad47eae4ea149bdced2043b7a45df3dae` and pinned predecessor `15aa75164145414f3d5ffb801401c52d40cc5bcc` binaries. It follows the primary 63 cases, six-case deep-warm repeat, same-process diagnostics and frozen-binary negative controls. All previous contrary observations remain evidence. This campaign makes no threshold waiver or automatic acceptance decision.

`schedule.json` was written before execution. SHA-256: `df6072749e4cb5e1e52164e46a39a7915221f30429633a825424e77369a5153a`. Six 37×23 cases (12/16-bit flat, ramp and noise) each receive 16 paired process blocks. Case order rotates and reverses by round; each case has eight predecessor-first and eight successor-first pairs. Each producer process performs 20,000 warmups and retains 1,000 observations of encode, owned decode, preparation and preparation-plus-encode. The consumer retains its original main-actor caller and public async boundary. Canonical fixture generation remains excluded. No case, operation, process or iteration is dropped, and there are no automatic reruns or outcome-dependent stopping rules.

Run once from the repository:

```sh
python3 work/m4-final-2026-10-21/diagnostics/tiny-confirmatory/run.py --output work/m4-final-2026-10-21/diagnostics/tiny-confirmatory/results-1
```

A fresh output directory is mandatory. The runner verifies frozen binary and common-Consumer hashes before and after collection, checks source equality to the pinned revisions, records toolchain/conditions, checks AC power at boundaries and every ten seconds, and stops with retained partial records if AC is lost or a process fails. Source comparison permits documentation-only working changes. No builds are performed. Every raw timing array, process command, producer identity, block, order, stderr and exit status is retained. An interrupted current process is saved with its available output and reason.

Analysis reports all 24 case/operation combinations, pooled medians, all paired median ratios and absolute deltas, median of block ratios, order-group medians, range/IQR/standard deviation and number of blocks above 1.05. The unit of resampling is a paired process block, never its 1,000 correlated observations. A deterministic 20,000-resample percentile bootstrap gives marginal 95% median intervals. A distribution-free order-statistic interval also reports the fourth and thirteenth ordered block observations; for 16 independent continuous observations this is a conservative nominal 95% interval with actual coverage 97.8729% (ties can make it more conservative).

Separate processes do not guarantee independence from the shared host or time. These intervals assume independent/exchangeable blocks, are not simultaneous across 24 metrics and cannot capture unobserved process/session effects or establish causation. Bootstrap estimates may underrepresent tails with only 16 blocks. Neither a pooled ratio below 1.05 nor a wide interval alone establishes equivalence, absence of regression, or a tiny-image speedup. No further repeat is scheduled automatically.
