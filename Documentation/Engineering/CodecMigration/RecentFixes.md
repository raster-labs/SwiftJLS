- **Pre-reserved owned destination storage:** `OwnedImageStorage.allocateReserved(byteCount:limits:)` and `OwnedImageStorage.init(reservedByteCount:allocationID:lease:)` (`Sources/SwiftJLS/ImageStorage.swift`), called by `ImageDestination.allocate(admittedDescriptor:limits:)` (`Sources/SwiftJLS/Image.swift`), start freshly allocated owned storage directly in `.writing` state with its fresh `allocationID` and `StorageWriteLease` before publication, avoiding one uncontended `reserveWrite()` atomic-plus-mutex cycle while keeping public `OwnedImageStorage.init`, `reserveWrite()`, post-publication gates and cancellation checks unchanged.
- **Direct metadata key predicate:** `JPEGMetadataEncoding.isSupportedKey(_ key: String) -> Bool` (`Sources/SwiftJLS/JPEGLS/JPEGLSMetadata.swift`) checks `JPEGLSMetadata.key`, `JPEGLSMetadata.spiffKey` and `JPEGLSMappingTables.key` via `image.metadata.requiredKeys.allSatisfy(Self.isSupportedKey)` and `image.metadata.entries.keys.allSatisfy(Self.isSupportedKey)`, removing one `128 B` temporary `Set` allocation in each of the 20 Linux encode workspace profiles (`4,432 -> 4,412` total phase calls across the 89 profiles under audited classifier `a1d97dca4c65b025992a5fed0a259ad2e76a412c6e202b293ccf70c80b5799d6`).
